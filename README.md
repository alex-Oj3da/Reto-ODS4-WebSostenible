# Reto-ODS4-WebSostenible

## 1. Análisis del Problema y Sostenibilidad
*(Responsable: Alumno A)*

### El "Bug" Educativo
En la educación actual todavía hay desigualdades en el acceso a recursos educativos. Muchas
plataformas son pesadas, consumen muchos datos y no funcionan bien con conexiones lentas o
dispositivos con poca batería. Esto provoca que algunos estudiantes tengan más dificultades
para acceder al aprendizaje y aumenta la brecha educativa.

### Nuestro "Parche" (Impacto ODS 4)
Nuestra plataforma ayuda a cumplir el Objetivo de Desarrollo Sostenible 4 – Educación de Calidad
ofreciendo contenidos educativos accesibles para todos. La web está diseñada para ser ligera
y cargar rápido incluso con internet lento, y cuenta con modo oscuro para ahorrar batería.
Así, más estudiantes pueden aprender de forma fácil y sostenible.
